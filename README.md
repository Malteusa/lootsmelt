# Loot Smelt
A Minecraft 1.7.10 mod that makes all entities drop cooked or "smelted" loot if they die while on fire.

This mod was made mainly for old mods that did not add proper checks for loot to be smelted on death by/while on fire.

Only affects mobs that can actually be set on fire. Mobs that are immune to fire will not have their drops smelted.

Also works for custom drops added using [Edit Mob Drops](https://www.curseforge.com/minecraft/mc-mods/edit-mob-drops) or custom smelting recipes added by [Craft/Minetweaker](https://www.curseforge.com/minecraft/mc-mods/crafttweaker)

Or any other mod that adds custom loot to mobs.

## Notes
The mod will attempt to smelt **ALL** loot, not just food. Such as raw ores or logs will be smelted into ingots or charcoal respectively.

Certain mods might have weapons/items that set the entities on fire without Fire Aspect or proper fire checks, these items will cause raw/uncooked drops if the entity dies in a single hit.
